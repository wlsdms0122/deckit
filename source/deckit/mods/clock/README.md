# Clock

The date and time in the status bar, the machine's, short, as the language you set writes them: the day, the date and the time to the minute, written again as each minute turns. A press on it does nothing.

It declares its item to the status bar (the Status Bar mod's README) and runs in the background from the start, setting the item's label. It is no app: it has no Dock item and no window of its own.
