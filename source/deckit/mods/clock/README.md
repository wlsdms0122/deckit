# Clock

The date and time in the status bar, the machine's, short, as the language you set writes them: the day, the date and the time to the minute, written again as each minute turns. A press on it opens the notification center (the Notifications mod's README, `notifications/center`), and a press again closes it; it shows pressed while the center is open. Where no mod provides `notifications/center`, a press does nothing.

It joins the status bar (the Status Bar mod's README) and runs while the bar shows it. It is no app: it has no Dock item and no window of its own.
