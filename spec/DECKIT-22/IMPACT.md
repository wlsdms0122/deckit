Beside the DECKITs, [the specification](../README.md), *What Deckit is*: "A host adds to them only by the means the system gives it: manifest fields, permissions and interfaces of its own." is "manifest fields and permissions of its own, and layers it stacks, each naming the permission that guards each request it handles. An interface a mod a host ships provides is an interface like any other."

No case of DECKIT-1 to DECKIT-21 changes its answer.
