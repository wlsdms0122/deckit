# What DECKIT-10 changes

| DECKIT | sentence | change | class |
|---|---|---|---|
| DECKIT-1 | *What the system gives a host*, *Steps*, *Formats*: the rows of format 3 | format 4: a `call` may write `listener`, which hands the request a function the host gives after its args, and `of`, which makes the request through what an earlier call of the same mod answered; the look `heard` answers what each listener was called with; a function in what a step reads is no value, and a refusal is read as `{ stage, kind }` | supplement |
| DECKIT-1 | Notes: "That a `part` of an array answer is taken of each element that holds the key: it waits on a request a case can make that answers an array of tables." | removed: `exports.contributions` answers an array of tables, and the case `a-part-of-an-array-answer-is-taken-of-each-element` holds it | supplement |
| DECKIT-2 | *interfaces*: "What providing and using come to (...) is the interfaces' DECKIT" | links [the interfaces](../DECKIT-10/SPEC.md) | supplement |
| DECKIT-2 | Interactions: "What `provides`, `uses` and `contributes` come to: the interfaces' DECKIT." | links [the interfaces](../DECKIT-10/SPEC.md) | supplement |
| DECKIT-3 | Notes: "That a host names the guards of its own interfaces' requests waits on the interfaces' DECKIT, which gives a host interfaces of its own." | waits on the embedding DECKIT, which gives a host interfaces, and links [the interfaces](../DECKIT-10/SPEC.md) for what one is; made in place, DECKIT-3 being a draft | supplement |
| DECKIT-6 | Interactions: "What each lifecycle is connected to as it starts: the interfaces' DECKIT." | links [the interfaces](../DECKIT-10/SPEC.md); made in place | supplement |
| DECKIT-7 | *The handle*, the rows `mods.pin(interface, mod)` and `exports.register(interface, exports)`, `exports.contributions(interface)`, `dependencies.onConnect`, `dependencies.onRefuse`: "the interfaces' DECKIT" | links [the interfaces](../DECKIT-10/SPEC.md); made in place | supplement |
| DECKIT-9 | Interactions: "the connection to an interface's owner (...) and its other members of `exports` and `dependencies`: the interfaces' DECKIT." | links [the interfaces](../DECKIT-10/SPEC.md); made in place | supplement |

No case of DECKIT-1 to DECKIT-9 changes its answer: the whole suite passes on the runner of format 4.
